# N-47 附件目录、版本详情与导出记录清理

状态：设计中 · 2026-11-26 · [用户决定 U-112](../design/14-decisions.md)

## 从附件名找到旧版本

用户想找到一个附件较早的可用版本，与当前候选比较，再清掉几次试制的快照。当前网页先取一页快照，再在浏览器中按名称分组。同名附件的旧版可能落在后面的页里，版本树和比较选项也只包含已加载的部分。已有勾选框用于加入或移出专题，删除需要逐项操作。[附件页](../../frontend/src/pages/AttachmentsPage.tsx) · [版本历史组件](../../frontend/src/components/AttachmentHistory.tsx)

建议按用户查找的两层对象组织页面。

1. **目录按附件名分页。** 普通附件和待评提交沿用各自的类别筛选。每个名称占一行，显示最新可见快照的标签或短摘要、发布时间和快照数。服务端先按类别、专题确定可见范围，再按名称聚合和分页。专题内的数量和“最新”均以该专题为范围。搜索保留名称、标签和快照 ID 三种入口，命中旧版时可以直接进入该版本。
2. **点名称打开独立详情。** 详情按发布时间从新到旧分页列出该名称的快照，支持按标签或 ID 定位。选中快照后再读文件清单，可查看父版本、识别分叉、与同名的另一个版本比较文件差异；父版本和比较基准都可跨页定位。保留从指定版本继续发布、停用、下载及附件名下的工作流记录。返回目录时保留专题、筛选和浏览位置。已有的快照链接以及携带 `snapshot` 和 `base` 的比较链接继续解析到原版本；链接指向专题外时标明范围。
3. **按快照批量移入回收站。** 详情中勾选具体版本，确认时展示附件名、所选版本和数量。选择绑定快照 ID，换页后已选数量可见，换附件、类别或专题时清空选择。专题成员操作沿用同一批快照，按钮分别写明“移出专题”和“移入回收站”。批删复用单项回收的权限和占用检查。页面汇总成功数，把受活动运行保护等失败项及原因留给用户处理。服务端在执行时再次检查，避免选择之后刚被运行引用的快照被删。[附件与快照](../design/03-configuration-attachments.md) · [回收站](../design/07-artifacts-export.md)

## 在导出页清理自己的记录

导出页目前列出本人的打包任务，可以刷新、下载就绪的压缩包、跳回来源运行。到期维护会回收压缩包并将状态改为已过期，列表行仍保留。建议在现有表格上提供逐条删除、勾选删除，以及跨全部页的“选择全部已过期”。最后一项先显示当前用户命中的总数，确认时固定选中范围。构建期间的自动刷新保留浏览位置和勾选，避免正在处理的旧记录突然消失。[导出页](../../frontend/src/pages/ExportsPage.tsx) · [导出服务](../../src/maestro/services/exports.py)

| 操作对象 | 建议行为 |
| --- | --- |
| 本人的就绪、失败、已过期记录 | 可移入回收站。从导出列表移除，原下载链接随即停止提供文件。记录仍关联原导出请求。 |
| 排队或构建中的导出 | 显示进行中的状态，结束后可删除。服务端也检查状态，以免删除与打包、释放读 pin 竞争。 |
| 恢复与物理删除 | 管理员沿用回收站操作。恢复后按原到期时间和包的实际可用性展示；在回收站中过期的包恢复为已过期。物理删除清除导出内容、残留压缩包并留下删除回执。来源运行、评分、产物及其保留期由原对象管理。 |

服务端增加按名称分页的附件目录查询，沿用按快照查询的公开接口。导出增加按状态筛选和回收入口，复用现有回收站的恢复、彻底删除与权限检查；个人导出列表保持按所有者查询。批量动作按项反馈，重复请求或部分失败后只需重试尚未完成的项。实施时同步公开契约、SDK 的相关资源接口，以及[网页](../design/11-web-ui.md)、[导出与回收](../design/07-artifacts-export.md)的系统说明。

## 验收

1. 构造多个附件名和超过两页的同名快照。目录中同一名称只占一行。用旧标签找到末页版本，与首页版本比较；从已有运行的比较链接进入也得到同一对版本。专题只选入其中两个快照时，目录正确显示两个，返回后仍在原专题。
2. 选中分布在两页的快照，其中一个正被运行使用。可删项进入回收站，受保护项显示原因；无法管理的快照改由直接请求删除时同样被拒。只执行“移出专题”时，快照在全局目录仍可见。
3. 两名成员各有多页已过期导出。一人在导出页选择全部已过期并确认，只清掉自己确认的记录；就绪项可单独删除，构建中项继续打包。重复清理后得到一致结果。
4. 分别在到期前后恢复已回收的就绪导出，验证下载随回收关闭、随有效恢复开放，超过原期限显示已过期。彻底删除导出后仍能打开来源运行、读取评分，并按产物自身的有效期下载。
