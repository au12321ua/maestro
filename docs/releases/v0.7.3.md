# Maestro 0.7.3

## 附件

- 附件目录按名称分页，可按专题筛选，也可用旧标签或快照 ID 定位对应版本。独立详情页支持跨页查看和比较同名快照，已有比较链接继续可用。
- 在详情页可以跨页勾选版本并批量移入回收站。结果逐项反馈，正在被运行使用的版本仍受保护。移出专题仍是独立操作。

## 导出

- 个人导出可按状态筛选，支持单条删除、批量删除和跨页选择全部已过期记录。排队和构建中的导出受保护。
- 管理员可在回收站恢复或彻底删除导出记录。恢复后的可下载状态遵循原到期时间和打包文件的可用性。来源运行、评分和原始产物仍按各自的保留规则管理。

## SDK 与 Agent skill

- SDK 新增按名称浏览附件、定位历史快照、按状态筛选和回收导出的接口。
- 随包提供的两个 Agent skill 增加在原工具项目内使用独立 SDK 环境、发布待测附件和在首次对照前选定专题的步骤。后续可用专题链接交接实验。

## 更新

从 0.7.2 按常规方式更新，数据库结构仍为 0016。使用 SDK 或 Agent skill 时，可安装同版本的 SDK，再同步随包 skill。

## 验证

- 功能候选 `41e3994` 在隔离环境中通过 1127 项 pytest 检查，38 项按测试前提跳过。演示服务与锁定 Runner 上通过 24 项 Playwright 检查，覆盖附件跨页定位与比较、批量回收的部分失败、个人导出隔离及到期前后恢复。
- 本轮功能验收使用隔离的测试和演示环境。真实 Hub、Docker、模型请求和系统级更新未纳入本轮功能验收。
