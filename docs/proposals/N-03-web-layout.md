# N-03 网页布局：侧边栏、长内容与表单对齐

状态：已确认 · 优先级：一 · 2026-10-28 · 相关：[11](../design/11-web-ui.md)、U-30、U-45；合并原 N-04（长任务名）

## 问题

用户在 0.3.x 与 N-09 实测中发现五处排版问题，都只涉及网页、都改所有页面共用的外框或写法，合成一项一次改完：

1. **导航分两套**：顶层是横向导航（10 项，窄屏折行），管理页内部又有自己的左侧子导航，两层布局不一致。
2. **长任务名撑坏排版**：试次列表、试次标题、结果表、产物表里的任务键原样显示，长名字挤掉其他列或换行错位。
3. **长内容把整页撑宽**：一行很长的日志、一个不带空格的长路径或 JSON，会让页面出现横向滚动条，整页变宽。原因是网格与 flex 的子元素默认“最小宽度 = 内容宽度”（例如执行页右栏是 `1fr`，不是 `minmax(0,1fr)`），里面的 `pre`、等宽长文本就把外框撑开。
4. **设置类表单的输入框不对齐**：管理页与设置页的表单各自手写网格（有的两栏、有的一栏、说明文字位置不一），标签折行或说明长短不同时输入框上下错开。项目已装 shadcn 的 `Field` 组件，表单都没用。
5. **执行页与产物页重复**：执行页每个试次下方列出该试次的全部产物下载链接，和“产物”标签页的功能重复，产物多时把步骤挤到上面、页面很长。

## 方案

### 侧边栏导航

```
┌──────────────┬──────────────────────────────────────┐
│ Maestro      │  页面标题                  [操作按钮] │
│              │                                      │
│ 工作台       │  内容区（宽度自适应，不再固定 7xl）  │
│ 实验         │                                      │
│   运行       │  “新建运行”是运行页上的按钮          │
│   批次       │                                      │
│   方案       │                                      │
│ 资源         │                                      │
│   数据集     │                                      │
│   附件       │                                      │
│   导出       │                                      │
│ 设置         │                                      │
│ 管理  ▾      │  ← 在 /admin 下展开 11 个分区，       │
│   成员与邀请 │    取代管理页自己的左侧子导航         │
│   …          │                                      │
│──────────────│                                      │
│ ● 可受理运行 │                                      │
│ admin(管理员)│                                      │
│ 退出         │                                      │
└──────────────┴──────────────────────────────────────┘
```

- “新建运行”不进侧边栏，只作运行页（与工作台）上的按钮。
- 新引入 shadcn 的 `Sidebar` 组件（连带它依赖的 `Sheet`、`Tooltip`）；系统状态、当前用户与退出放侧边栏底部，不可受理时的横幅仍在内容区顶部。
- 侧边栏可收起成只显示图标的窄条，收起状态存浏览器本地（只是个人偏好）。窄屏（手机宽度）变成抽屉，从左上角按钮打开。
- 管理页的分区并入侧边栏，管理页本身只剩内容区。URL 不变（`/admin/<分区>`）。

### 长名字

- 任务键、产物路径、运行名等长文本统一用一个组件显示：单行截断，悬停显示全名，旁边一个复制按钮。
- 同一列表里的名字有共同前缀（例如同一数据集的任务都以 `swebench-django__django-` 开头）时，省略中间、保留开头和能区分彼此的结尾，例如 `swebench…-11099`。
- 试次标题、运行标题这类“只有一个”的位置不截断，允许在任意字符处换行。

### 不再撑宽页面

- 定一条写法规则并全站改一遍：主内容区与所有网格、flex 中放内容的格子加 `min-w-0`，网格列写 `minmax(0,1fr)`；日志与代码块在自己的框里横向滚动；定义列表里的长值允许任意处换行；宽表格在自己的卡片里横向滚动。
- 网页冒烟测试加一个故意很长的任务名和一行几千字符的日志，在桌面与手机宽度下检查页面没有横向滚动条（`document.scrollingElement.scrollWidth` 不超过窗口宽度）。

### 表单对齐

- 设置类表单（管理页各分区、设置页、Harness 发布、安装网络等）统一一种排法：桌面上标签一列固定宽度、输入框一列，说明文字放在输入框下方；窄屏变成上下排列。用 `Field` 组件实现，不再各页手写网格。
- 弹窗、筛选栏这类短表单保持上下排列，不套用两栏。

### 执行页不再列产物

- 执行页去掉每个试次下方的产物链接列表，改成一行“产物 N 个 →”，点击跳到产物标签页并只看这个试次（产物页加试次筛选，记在 URL 里）。
- 步骤展开后的日志保留，下载单个日志的链接放在日志框标题行。
- 产物页以后按 N-05 改成 任务 → 试次 → 执行尝试 的目录树；本项只加筛选，不预先做目录树。

### 不做

- 不改页面的路由与内容，只改外框与排版；轨迹的结构化显示（每步卡片、折叠工具输出）另写提案。
- 不做深色模式切换与多语言（N-18）。

## 影响

- 只改前端与 [11](../design/11-web-ui.md) 第 1 节的导航描述；不改 API、数据库与部署。
- 冒烟测试中按顶部导航找链接的写法（`header` 里的链接、管理子导航）要跟着改。
- 改动遍及所有页面外框，宜在其他前端提案（N-05、N-06、N-07）之前合入，减少冲突。

## 验收

- 桌面（1280 宽）与手机（390 宽）下，各页面都没有横向滚动条，包括带超长任务名和超长日志行的运行页。
- 所有页面从侧边栏可达；管理页只有一层导航；侧边栏收起、展开与刷新后保持。
- 设置页与管理页各分区的表单，同一表单内输入框左边缘对齐。
- 执行页不再列出产物；“产物 N 个 →”跳到只显示该试次的产物页。
- 网页冒烟测试通过，并附桌面与手机宽度的截图。

## 已定（U-45）

1. 侧边栏按上图分组；“新建运行”只作运行页上的按钮。
2. 长名字有共同前缀时省略中间。
3. 执行页完全去掉产物列表，换成跳到按试次筛选的产物页的链接。
