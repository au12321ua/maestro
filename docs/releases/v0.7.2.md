# Maestro 0.7.2

## SDK 与 Agent 工作区

- 工作区新增 `update-maestro.py`。脚本读取所连接的正式服务版本，安装同版本的 SDK，并同步随包提供的 Agent skill。
- 新建工作区提供 `.env.example`，更新脚本与 Agent 可共用服务地址和 PAT 文件路径。升级 SDK 后，已有工作区可重跑 `workspace.init(".")` 补齐模板。已有 `.gitignore` 的工作区需自行补上 `/.env`。

## 实验专题

- 专题列表按行显示名称、目的、更新时间和标识。专题概览集中展示最新交接与运行，进行中的运行排在最前，便于查看状态、分数和提交时间。
- 宽屏将已选引用和运行实际使用的材料放在概览旁边，窄屏按顺序排列。引用和材料目录可在原卡片内展开，运行、集合、数据集和附件入口集中在工具栏。

## 更新

从 0.7.1 按常规方式更新，继续使用数据库结构 0016。

## 验证

- 在 `d8e22b3` 上通过 26 项 SDK 测试，并用实际安装的 SDK wheel、临时服务和测试 PAT 验证工作区更新与配置。
- 在 `8a1b65a` 上用隔离的演示执行器通过 21 项 Playwright 冒烟测试，核对桌面和手机宽度下的页面。数据集上传场景因未配置 Runner 而跳过。
- 本轮功能验收范围为隔离的 SDK 和网页流程。真实 Hub、Docker、模型调用和系统级更新未纳入本轮验收。
