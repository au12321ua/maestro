# Maestro 0.7.0

实验专题让团队用一个链接组织运行、比较和证据。网页新建运行会显示团队默认并发，已结束运行的产物可按需保留。

## 更新后

- 从 0.6.0 更新时，安装包的更新流程会备份数据库并运行迁移 0015、0016。已有账户、数据集、运行、评分与产物继续使用原有标识。源码运行的实例在停服后执行 `maestro db upgrade`，再启动新版本。
- SDK 与服务使用同一版本。升级 SDK 至 0.7.0 后，Agent 可通过 `client.topics.open(url_or_id)` 从网页分享的实验专题链接接手。

## 破坏性变更

- 0.6.0 需要数据库结构 0014。数据库升级到 0016 后，回退到 0.6.0 需恢复升级前的数据库备份。

## 新功能

- **实验专题**。专题可选入运行、集合、数据集和附件快照。概览显示活动和近期运行、评分覆盖、运行实际使用的版本和最新交接。运行、集合、数据集与附件目录可按专题搜索、分页和批量整理。交接可附运行、试次或产物引用。
- **SDK 专题提交**。同一个句柄可读取概览、分页明细和交接，也可向指定专题提交、重跑或提交批次。运行受理与加入专题共用一个事务，断线重试保留幂等语义。
- **自动并发**。新建运行默认显示团队并发上限，可主动调低。使用方案或原运行的显式值时，表单显示数值和来源。重复次数仍决定计划试次数。
- **手动保留运行产物**。已结束运行可在网页或 SDK 查看保留空间、可保留大小和缺失项。所选文件继续通过原链接提供。管理员可设置团队配额，解除保留后按原到期时间清扫。

## 验证

- 合并业务基线为 `23cff6e`。在内容相同的 `62bcea8` 上，全量 Python 测试通过 1121 项，隔离 Chromium 冒烟通过 22 项。另验证跨页定位专题中的数据集、打开版本并刷新后保留范围。
- 使用 0.6.0 正式安装包创建隔离数据库，升级 `0014 → 0016` 后核对已评分运行、队列、冻结配置、产物索引和可读文件的 SHA-256，并将原运行加入专题。
- 正式候选接受完整源码 CI。正式构建在全新环境安装服务和 SDK wheel，核对元数据、入口、网页、清单和摘要。
